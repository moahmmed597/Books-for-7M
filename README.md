## 🌟 مميزات مستودع 7M الإصدار الثاني (v2.2.0 Features)

1. **دعم القراءة والاستماع (Read 📖 & Listen 🎧):**
   - **الكتب المقروءة:** محرك عرض صفحات تلفزيونية داكن عريض (16:9 SVG بدقة 1280x720) مع خطوط واضحة وترقيم صفحات.
   - **الكتب الصوتية:** بث صوتي مباشر بصيغة MP3 من سيرفرات سريعة تدعم التقديم والتأخير (HTTP Range Requests) وحفظ آخر ثانية توقفت عندها تلقائياً.
   - **الكتب الهجينة (Hybrid):** ظهور زري 📖 و 🎧 معاً؛ تواصل القراءة من نفس الفصل الذي استمعت إليه والعكس!
2. **تحكم كامل بالريموت كنترول (Remote Control Controls):**
   - **OK:** تشغيل / إيقاف مؤقت.
   - **◀ / ▶:** تقديم / تأخير 30 ثانية.
   - **▲ / ▼:** الفصل السابق / التالي.
   - **+CH / -CH:** تقليب الصفحات المعروضة أمامك أثناء الاستماع!
   - **تعليق على OK:** قائمة تغيير السرعة (من 0.75x حتى 2.0x)، الفصول، وحفظ العلامات المرجعية.
3. **متوافق 100% مع مواصفات Stremio 7M الرسمية:**
   - ضبط اتجاه النصوص وتقليب الصفحات عبر حقل `"lang": "ar"` و `"lang": "en"`.
   - إدراج مسارات الملفات عبر حقل `"entry"`.
   - أمان تام، بدون كابتشا أو إعلانات أو شهادات منتهية.

## ⚙️ التوثيق التقني لنظام الصوت والقراءة (Developer Spec for Claude)

> [!NOTE]
> هذا القسم يوضح لـ **Claude** البنية الهندسية لكيفية عمل الإضافات الصوتية والمقروءة في تطبيق **7M**:

### 1. بروتوكول الكتب الصوتية (`audioTracks`):
عندما تحتوي الإضافة على دالة `audioTracks(id)`:
```javascript
async function audioTracks(id) {
  return [
    {
      id: "ch1",
      title: "الفصل الأول",
      url: "https://.../chapter01.mp3", // رابط مباشر يدعم HTTP Range / Seeking
      duration: 1540,                  // بالثواني
      chapter: "1"                      // رقم الفصل المطابق لدالة chapters()
    }
  ];
}
```
- **إذا كانت `chapters()` تعيد `[]`:** يتعامل التطبيق مع الكتاب كـ (Audio-only) ويفتح شاشة مشغل الصوت فوراً بدون زر قراءة.
- **إذا كانت `chapters()` و `audioTracks()` تعيدان بيانات معاً:** يظهر للمستخدم زري **📖 Read** و **🎧 Listen**، مع ربط رقم الفصل بين القراءة والاستماع تلقائياً.

### 2. بروتوكول القراءة النصية التلفزيونية (`pageUrls`):
تقوم الإضافة بتقسيم النص لصفحات عريضة وتحويلها فوراً إلى صور SVG مشفرة كـ Data URI:
```javascript
'data:image/svg+xml;charset=utf-8,' + encodeURIComponent(svg)
```
- أبعاد 16:9 (`1280x720`).
- اتجاه النص `direction: rtl` للعربية و `direction: ltr` للإنجليزية.
