## 🌟 نظرة عامة (Overview)

تم بناء هذا المستودع خصيصاً لتمكين تطبيق **7M** المخصص للشاشات الذكية من قراءة الروايات والكتب النصية بكفاءة تامة، مع الحفاظ على أعلى معايير التوافق والأمان والسرعة.

### 🛡️ ضمان الأمان والاستقرار بنسبة 100% (Strict SSL & Zero-Cloudflare):
1. **خالٍ تماماً من كبتشا وكلاود فلير (Zero Cloudflare Challenges):** تم فحص واختيار جميع المصادر لتعمل عبر واجهات برمجة مفتوحة ومباشرة دون التعرض لحجب `Could not load this page` أو حظر المتصفح في الشاشات الذكية.
2. **شهادات أمان مشددة (Valid Strict SSL):** جميع الروابط تستخدم شهادات SSL/TLS رسمية صالحة ومطابقة لتفادي مشاكل التحقق في متصفحات شاشات سامسونج وAndroid TV.
3. **سرعة استجابة فائقة:** استجابة مباشرة عبر خوادم سريعة تضمن استعراض الفصول في أجزاء من الثانية.

## ⚙️ التوثيق التقني لمحرك العرض (Technical Documentation for Claude)

> [!NOTE]
> هذا القسم موجه للمساعد الذكي **Claude** (المشغل الأساسي والمطور للتطبيق) لفهم كيفية بناء وتطوير وصيانة إضافات الكتب في تطبيق **7M**.

### 1. المشكلة الهندسية الأساسية (The Core Architecture Challenge)
تطبيق **7M** بُني في الأساس كمستعرض مانجا وكوميكس؛ لذلك يتوقع أن تُرجع دالة `pageUrls(chapterId)` مصفوفة من روابط الصور (`string[]`). في الكتب والروايات النصية، لا توجد ملفات صور جاهزة لكل صفحة، وتمرير نصوص HTML أو روابط نصوص خام كان سيتسبب في تعطل مشغل الصور في الشاشة وظهور شاشة سوداء.

### 2. الحل: محرك تحويل النصوص إلى صفحات تلفزيونية ديناميكية (TV Book Page Engine)
قمنا بابتكار وبناء **محرك عرض صفحات الكتب (TV SVG Page Renderer)** داخل كل إضافة:
1. **استخراج ومعالجة النص:** يتم جلب نص الفصل بصيغة HTML أو نص خام، وتنظيفه من وسوم الإعلانات والتنسيقات الزائدة (`stripHtml`).
2. **تقسيم الصفحات الذكي (`splitIntoPages`):** يتم احتساب عدد الكلمات في كل فقرة، وتقسيم الفصل إلى كتل متناسقة (~220-250 كلمة لكل صفحة) بحيث لا يفيض النص عن حدود الشاشة بدقة 1080p و 720p.
3. **توليد لوحات الرسوميات المتجهة (`renderSvgPage`):** يتم إنشاء لوحة SVG بدقة 16:9 عريضة (`1280x720`) مصممة خصيصاً للشاشات الكبيرة:
   - **الخلفية:** تدرج لوني ليلي هادئ للعينين (`#121418` إلى `#0a0c0f`).
   - **الإطار الداخلي:** بطاقة قراءة أنيقة مع حواف دائرية (`rx="16"`).
   - **العنوان:** ترويسة ذهبية أنيقة تظهر اسم الفصل أو الكتاب (`#f59e0b` أو `#38bdf8`).
   - **الخط وتوزيع النص:** استخدام `foreignObject` لضمان تدفق النص بخطوط نظام واضحة مقروءة من مسافة 3-4 أمتار أمام التلفزيون (حجم 25px مع تباعد أسطر 1.9).
   - **دعم الاتجاهات (RTL / LTR):** دعم كامل للغة العربية من اليمين لليسار (`direction: rtl; text-align: justify`)، وللغة الإنجليزية من اليسار لليمين (`direction: ltr; text-align: left`).
   - **تذييل الصفحة:** عداد صفحات ديناميكي يوضح رقم الصفحة الحالية من إجمالي صفحات الفصل (مثال: `صفحة 1 من 12`).
4. **الترميز الفوري (Data URI Output):** يتم تحويل كود الـ SVG مباشرة إلى رابط بيانات:
   ```javascript
   'data:image/svg+xml;charset=utf-8,' + encodeURIComponent(svg)
   ```
   هذا يسمح لمشغل الصور في تطبيق **7M** بالتعامل مع الصفحات كصور عادية فائقة الدقة والوضوح (Vector Sharpness) دون الحاجة لرفعها على خوادم خارجية أو استهلاك باندويث إضافي!

---

### 3. عقد تكامل الإضافة (Plugin Contract for 7M)

كل إضافة في المستودع تصدر كائناً يحتوي الدوال القياسية التالية:

```typescript
interface NovelPlugin {
  id: string;
  name: string;
  
  // 1. جلب الأعمال الأكثر رواجاً / الرئيسية
  popular(offset: number): Promise<Array<{
    id: string;
    title: string;
    cover?: string;
  }>>;

  // 2. البحث بالاسم أو الكلمة المفتاحية
  search(query: string, offset: number): Promise<Array<{
    id: string;
    title: string;
    cover?: string;
  }>>;

  // 3. جلب تفاصيل العمل والوصف والمؤلف
  detail(id: string): Promise<{
    id: string;
    title: string;
    cover?: string;
    description?: string;
    author?: string;
    status: 'ongoing' | 'completed';
  }>;

  // 4. جلب قائمة الفصول
  chapters(id: string): Promise<Array<{
    id: string;
    chapter: string;
    title: string;
    number: number;
  }>>;

  // 5. جلب صفحات الفصل (مصفوفة من صور SVG Data URIs)
  pageUrls(chapterId: string): Promise<string[]>;
}
```

### 4. كيفية تشغيل الفحص والتحقق الآلي (Automated Verification)

للتأكد من سلامة جميع الإضافات والمصادر، يتم تنفيذ سكريبت الفحص الشامل:

```bash
node verify_all_plugins.mjs
```

يختبر السكريبت تلقائياً:
- استجابة `popular()` واستخراج العناوين والأغلفة.
- جلب تفاصيل العمل الأول عبر `detail()`.
- جلب فصول العمل عبر `chapters()`.
- تحويل أول فصل إلى صفحات SVG عبر `pageUrls()` والتحقق من صحة تشفير ومحتوى الـ SVG.
